# MCP Registry

Registre des serveurs MCP autorisés pour l'organisation SoftFluent.

## 🚀 Demander l'ajout d'un serveur MCP

Pour ajouter un nouveau serveur MCP à la liste blanche :

1. **Créer une Issue** dans ce dépôt
2. **Utiliser le template** [`mcp-server-request.md`](mcp-server-request.md)
3. **Compléter les sections** :
   - Détails du serveur (nom, publisher, package)
   - Justification métier
   - Informations de sécurité
   - Niveau de risque estimé

4. **Soumettre** - L'équipe sécurité reviendra vers vous

## ⏱️ Délai

Comptez **2-5 jours** pour la revue de sécurité selon le niveau de risque.
